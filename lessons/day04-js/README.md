## 1. Python・Rust との違い（3分）

| やりたいこと | Python | Rust | JavaScript |
| --- | --- | --- | --- |
| 関数を定義 | `def add(a, b):` | `fn add(a: i32, b: i32) -> i32` | `function add(a, b) { }` |
| 短い関数 | `lambda x: x * 2` | `\|x\| x * 2` | `(x) => x * 2` |
| デフォルト引数 | `def f(x=10):` | なし | `function f(x = 10) { }` |
| 値を返す | `return x` | 最後の式 or `return` | `return x`（書かないと `undefined`） |
| 引数の型 | 書かなくてよい | 必須 | 書けない（TypeScript なら書ける） |
| 引数の数が違う | `TypeError` | コンパイルエラー | **エラーにならない** |

覚えるのは次の 3 点です。

1. **`function` もアロー関数も、どちらも実務で使う**。短い処理や、関数に渡す関数（コールバック）はアロー関数で書くことが多いです。
2. **`return` を書き忘れると `undefined`**。Rust のように最後の式が戻り値になることはありません。ただし `{ }` なしの 1 行アロー関数だけは、式の値がそのまま返ります。
3. **引数の数はチェックされない**。足りない引数は `undefined` になり、余った引数は無視されます。

## 2. サンプルを実行して読む（5分）

```bash
node lessons/day04-js/sample.js
```

[sample.js](sample.js) のアロー関数の 2 つの書き方を見比べてください。

```js
const multiply = (a, b) => a * b;      // 1行なら { } と return を省略できる
const square = (x) => {
  const result = x * x;                // 複数行なら { } と return が必要
  return result;
};
```

`{ }` を付けたのに `return` を忘れると `undefined` が返ります。初心者がよくはまるところです。

## 4. 確認クイズ（2分）

**Q1.** 次の関数を `double(4)` と呼んだ結果は？

```js
const double = (x) => { x * 2 };
```

<details><summary>答え</summary>

`undefined` です。`{ }` を付けると関数の本体（ブロック）になるので、`return x * 2;` と書く必要があります。`(x) => x * 2` と書けば `8` が返ります。

</details>

**Q2.** `function f(a, b = 5) { return a + b; }` のとき、`f(1)` と `f(1, undefined)` と `f(1, null)` の結果は？

<details><summary>答え</summary>

`6`、`6`、`1` です。デフォルト値が使われるのは、引数が `undefined` のときだけです。`null` は「値がない」という値として渡されるので、`1 + null` が計算されて `1` になります。

</details>

**Q3.** Python の `sorted(nums, key=lambda x: -x)` のように「関数を引数に渡す」ことは JavaScript でもできる？

<details><summary>答え</summary>

できます。関数は普通の値なので、変数に入れたり引数に渡したりできます。Day 10 で学ぶ `map`・`filter` などは、まさにアロー関数を渡して使うメソッドです。

</details>

## 日本企業での使われ方

- React などのフロントエンド開発では、画面の部品（コンポーネント）そのものを関数で書きます。`const Button = (props) => { ... }` のようなアロー関数は毎日目にする書き方です。
- 「税込計算」「送料計算」のような業務ルールは、テストしやすいように小さな関数に分けておくのが基本です。

## 今日のまとめ

- 関数は `function` とアロー関数 `=>` の 2 通り。`{ }` を付けたら `return` を忘れない
- デフォルト引数は `引数 = 値`。`undefined` のときだけ使われる
- 引数の数はチェックされないので、呼び出す側が注意する
