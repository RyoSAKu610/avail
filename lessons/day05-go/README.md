## 1. Python・Rust との違い（3分）

| やりたいこと | Python | Rust | Go |
| --- | --- | --- | --- |
| 関数を定義 | `def add(a, b):` | `fn add(a: i32, b: i32) -> i32` | `func add(a, b int) int` |
| 型の位置 | （ヒントは `a: int`） | 名前の後ろ | 名前の後ろ（`:` は付けない） |
| 値を 2 つ返す | タプル `return a, b` | タプル `(a, b)` | `return a, b`（タプル型はない） |
| いらない値を捨てる | `_, b = f()` | `let (_, b) = f();` | `_, b := f()` |
| 可変長引数 | `def f(*nums):` | なし | `func f(nums ...int)` |
| デフォルト引数 | `def f(x=10):` | なし | **なし** |

覚えるのは次の 3 点です。

1. **型は名前の後ろ**。`a, b int` のように、同じ型が続くときはまとめて書けます。
2. **戻り値を複数返せる**。Go では「結果, エラー」の 2 つを返す関数がとても多く、Day 20 のエラー処理の土台になります。
3. **いらない戻り値は `_` で捨てる**。受け取った変数を使わないとコンパイルエラーになるからです。

## 2. サンプルを実行して読む（5分）

```bash
go run ./lessons/day05-go/sample
```

[sample/main.go](sample/main.go) で特に見てほしいのは、標準ライブラリの関数も 2 つの値を返すところです。

```go
n, err := strconv.Atoi("123") // 文字列 → int
fmt.Println(n, err)           // 123 <nil>  (nil は「エラーなし」)
```

Python の `int("123")` は失敗すると例外を投げますが、Go の `strconv.Atoi` は「結果」と「エラー」を一緒に返します。これが Go らしい書き方です。

## 4. 確認クイズ（2分）

**Q1.** 次の関数定義は正しい？

```go
func area(w, h int) int {
	return w * h
}
```

<details><summary>答え</summary>

正しいです。`w, h int` は `w int, h int` の省略形です。

</details>

**Q2.** Go にデフォルト引数がないとき、「税率を省略したら 10%」を実現するには？

<details><summary>答え</summary>

方法はいくつかあります。よく使われるのは、`withTax(price int)` と `withTaxRate(price, rate int)` のように関数を 2 つ用意する方法です。設定項目が多いときは、Day 17 で学ぶ構造体（struct）に設定をまとめて渡します。

</details>

**Q3.** `func sum(nums ...int) int` に、スライス `prices := []int{1, 2, 3}` を渡すには？

<details><summary>答え</summary>

`sum(prices...)` と書きます。後ろに `...` を付けると、スライスを展開して渡せます。Python の `sum_all(*prices)` と同じ考え方です。

</details>

## 日本企業での使われ方

- Go のコードレビューでは「エラーを返す関数の戻り値を `_` で捨てていないか」がよく確認されます。今日の `_` は便利ですが、エラーを捨てるのは基本的に NG です（Day 20 で学びます）。
- デフォルト引数やオーバーロード（同じ名前で引数の違う関数）がないため、関数名で意味をはっきりさせるのが Go の流儀です。

## 今日のまとめ

- `func 名前(引数 型) 戻り値の型`。同じ型の引数はまとめて書ける
- 戻り値を 2 つ以上返せる。いらないものは `_` で捨てる
- デフォルト引数はない。`...int` で可変長引数
