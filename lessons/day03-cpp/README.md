## 1. Rust・Go との違い（3分）

| やりたいこと | Rust | Go | C++ |
| --- | --- | --- | --- |
| 変更できない変数 | `let x = 1;` | `const`（定数のみ） | `const int x = 1;` |
| 変更できる変数 | `let mut x = 1;` | `x := 1` | `int x = 1;` |
| 型推論 | `let x = 1;` | `x := 1` | `auto x = 1;` |
| 値を入れずに宣言 | 使う前に代入が必須 | ゼロ値が入る | **中身が不定**（危険） |
| 小数への型変換 | `x as f64` | `float64(x)` | `static_cast<double>(x)` |
| 画面に出力 | `println!("{x}")` | `fmt.Println(x)` | `std::cout << x << "\n";` |
| 実行の流れ | `cargo run` | `go run` | `g++` でコンパイル → 実行 |

Python では `x = 1` がそのまま変更可能な変数になります。C++ もこれと同じで、**何も付けなければ変更できる**変数になります。Rust とは逆なので注意しましょう。

覚えるのは次の 3 点です。

1. **変更しない値には `const` を付ける**。Rust の `let` に相当します。付け忘れてもエラーにならないので、自分で意識して付けます。
2. **変数は必ず初期化する**。`int x;` と書くと中身は不定です。Go のゼロ値も Rust のコンパイルエラーもありません。
3. **`int` 同士の割り算は切り捨て**。小数が欲しいときは `static_cast<double>(x)` で片方を `double` にします。

## 2. サンプルをコンパイル・実行して読む（5分）

リポジトリのルートで実行します。

```bash
g++ -std=c++17 -Wall -Wextra lessons/day03-cpp/sample.cpp -o sample.out
./sample.out
```

オプションの意味は次のとおりです。

| オプション | 意味 |
| --- | --- |
| `-std=c++17` | C++17 の規格でコンパイルする |
| `-Wall -Wextra` | 警告をたくさん出してもらう（実務でもほぼ必須） |
| `-o sample.out` | できあがる実行ファイルの名前 |

[sample.cpp](sample.cpp) で特に見てほしいのは、`{}` を使った初期化です。

```cpp
int a{42};
// int b{3.7};  ← コンパイルエラー (narrowing): 小数点以下が消えるため
int c = 3.7;  // = だと 3 になってしまう (コンパイラによっては警告すら出ない)
```

`{}` で初期化すると、小数点以下が消えるような危ない変換をコンパイラが止めてくれます。Rust の「暗黙の型変換はしない」に少し近づけるための書き方です。

**未初期化の変数について**：次のコードは実行するたびに違う値が出ることがあり、「未定義動作」と呼ばれます。プログラムが何をしてもおかしくない状態です。

```cpp
int x;
std::cout << x << "\n";  // 何が表示されるか分からない
```

`-Wall` を付けると `'x' is used uninitialized` という警告で教えてくれることがあります。警告は無視せずに直しましょう。

## 4. 確認クイズ（2分）

**Q1.** `std::cout << 10 / 4 << " " << 10.0 / 4;` の出力は？

<details><summary>答え</summary>

`2 2.5` です。`10 / 4` は `int ÷ int` なので切り捨てられます。片方が `double`（`10.0`）なら小数で計算されます。

</details>

**Q2.** Rust の `let x = 5;` に一番近い C++ の書き方は？
(A) `int x = 5;`　(B) `const int x = 5;`　(C) `auto x = 5;`

<details><summary>答え</summary>

**(B)** です。Rust の `let` は変更できない変数なので、C++ では `const` を付けます。(A) と (C) は Rust の `let mut` に相当します。

</details>

**Q3.** `bool ok = true; std::cout << ok;` の出力は？

<details><summary>答え</summary>

`1` です。C++ の `bool` は、そのまま出力すると `1` / `0` になります。`true` / `false` で表示したいときは、先に `std::cout << std::boolalpha;` を流します。

</details>
