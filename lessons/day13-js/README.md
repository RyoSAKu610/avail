## 1. Python・Rust との違い（3分）

| やりたいこと | Python | Rust | JavaScript |
| --- | --- | --- | --- |
| 決まった項目のデータ | `dict` / `dataclass` | `struct` | オブジェクト `{ name: "佐藤" }` |
| 辞書（キーが増減する） | `dict` | `HashMap` | `Map` |
| 値を取り出す | `d["k"]` / `d.get("k")` | `m.get("k")` | `m.get("k")` |
| ないキー | `KeyError` / `None` | `None` | `undefined` |
| 取り出して変数に | `a, b = pair` | `let (a, b) = pair;` | `const [a, b] = pair;` / `const { name } = obj;` |
| 文字数 | `len(s)` | `s.chars().count()` | `[...s].length` |
| UTF-8 バイト数 | `len(s.encode())` | `s.len()` | `new TextEncoder().encode(s).length` |

覚えるのは次の 3 点です。

1. **項目が決まっているデータはオブジェクト、キーが増減する辞書は `Map`**。`Map` はキーの順番が追加順に保たれ、`size` で個数がわかります。
2. **分割代入**で、オブジェクトや配列から変数をまとめて取り出せます。React のコードなどで非常によく使われます。
3. **`s.length` は「UTF-16 の単位の数」**。日本語のひらがな・漢字は 1 文字 = 1 ですが、絵文字などは 2 になります。見た目の文字数は `[...s].length` で数えます。

## 2. サンプルを実行して読む（5分）

```bash
node lessons/day13-js/sample.js
```

[sample.js](sample.js) の最後の、文字数の部分を見てください。

```js
console.log("山田太郎".length); // 4
console.log("🍎".length);       // 2 ← 絵文字などは 2 と数えられる (UTF-16 のため)
console.log([..."🍎"].length);  // 1 ← [...文字列] なら見た目どおりに数えられる
console.log(new TextEncoder().encode("山田太郎").length); // 12 (UTF-8 のバイト数)
```

日本の業務システムでは「氏名は 20 文字以内」「このデータベースの列は 60 バイトまで」のように、文字数とバイト数の両方の制限がよく出てきます。

## 4. 確認クイズ（2分）

**Q1.** `const { name, age = 20 } = { name: "鈴木" };` のあと、`age` はいくつ？

<details><summary>答え</summary>

`20` です。分割代入でもデフォルト値が使えます。元のオブジェクトに `age` がない（`undefined`）ので、デフォルト値が入ります。

</details>

**Q2.** 普通のオブジェクトを辞書として使うと困るのはどんなとき？

<details><summary>答え</summary>

たとえば次のようなときです。

- キーが文字列（または Symbol）に限られ、数値のキーも文字列に変換されてしまう
- 個数を調べるのに `Object.keys(obj).length` と書く必要がある
- `"constructor"` のような名前のキーが、元からある機能とぶつかる

キーが増えたり減ったりする辞書には `Map` を使うと安全です。

</details>

**Q3.** `"こんにちは".slice(0, 3)` の結果は？

<details><summary>答え</summary>

`"こんに"` です。ひらがなは 1 文字ずつ数えられます。ただし絵文字を含む文字列を `slice` すると、絵文字の途中で切れて文字化けすることがあります。

</details>

## 日本企業での使われ方

- 入力フォームで「全角 10 文字以内」などをチェックする処理はよくあります。絵文字や旧字体を含む名前で文字数がずれないか、テストで確認するのが大切です。
- API から受け取った JSON はオブジェクトになります。`const { id, name } = response;` のように分割代入で取り出すのが定番です。
