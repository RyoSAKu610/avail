## 1. Python・Rust との違い（3分）

| やりたいこと | Python | Rust | JavaScript |
| --- | --- | --- | --- |
| 作る | `[3, 1, 2]` | `vec![3, 1, 2]` | `[3, 1, 2]` |
| 末尾に追加 | `xs.append(4)` | `xs.push(4)` | `xs.push(4)` |
| 長さ | `len(xs)` | `xs.len()` | `xs.length` |
| 末尾の要素 | `xs[-1]` | `xs.last()` | `xs.at(-1)` |
| 変換 | `[x * 2 for x in xs]` | `xs.iter().map(\|x\| x * 2)` | `xs.map((x) => x * 2)` |
| 絞り込み | `[x for x in xs if x > 1]` | `.filter(\|x\| ...)` | `xs.filter((x) => x > 1)` |
| 合計 | `sum(xs)` | `xs.iter().sum()` | `xs.reduce((s, x) => s + x, 0)` |
| 並べ替え（新しく作る） | `sorted(xs)` | （コピーして `sort`） | `[...xs].sort((a, b) => a - b)` |

覚えるのは次の 3 点です。

1. **`map`・`filter` は新しい配列を返す**。元の配列は変わりません。Rust のイテレータに似ていますが、`collect()` は不要です。
2. **`sort()` は引数なしだと文字列として並べる**。数値は必ず `(a, b) => a - b` を渡します。
3. **`sort()` は元の配列を書き換える**。元を残したいときは `[...xs]` でコピーしてから並べ替えます（新しめの環境なら `xs.toSorted()` も使えます）。

## 2. サンプルを実行して読む（5分）

```bash

```

[sample.js](sample.js) の `sort` の結果を確認してください。

```js
console.log([10, 9, 100].sort());                // [ 10, 100, 9 ]
console.log([10, 9, 100].sort((a, b) => a - b)); // [ 9, 10, 100 ]
```

引数なしの `sort()` は、`"10"`・`"100"`・`"9"` という文字列として辞書順に並べます。JavaScript で最も有名な落とし穴の一つです。

## 4. 確認クイズ（2分）

**Q1.** `[1, 2, 3].map((x) => x * 10).filter((x) => x > 10)` の結果は？

<details><summary>答え</summary>

`[20, 30]` です。`map` で `[10, 20, 30]` になり、`filter` で 10 より大きいものだけが残ります。このようにメソッドをつなげて書けます（メソッドチェーン）。

</details>

**Q2.** `const xs = [1, 2]; xs.push(3);` はエラーになる？

<details><summary>答え</summary>

なりません。`const` は「変数に別の配列を入れ直せない」という意味で、配列の中身は変更できます（Day 1 の復習）。

</details>

**Q3.** `[].reduce((s, x) => s + x)` のように、初期値なしで空の配列に `reduce` を使うと？

<details><summary>答え</summary>

`TypeError: Reduce of empty array with no initial value` になります。合計を求めるときは、第 2 引数に初期値 `0` を渡す習慣をつけましょう。

</details>

## 日本企業での使われ方

- React などでは、配列から画面の一覧を作るときに `items.map((item) => <li>{item.name}</li>)` のように `map` を使います。フロントエンドでは毎日のように書く形です。
- 「元のデータを書き換えない（イミュータブル）」書き方が好まれます。`sort` や `push` のように配列を書き換えるメソッドを使うときは、コピーを作ってからにするのが安全です。

## 今日のまとめ

- `map`（変換）・`filter`（絞り込み）・`reduce`（集計）で、ループなしでデータを加工できる
- 数値の `sort` には `(a, b) => a - b` を渡す
- `sort` は元を書き換えるので、残したいなら `[...xs]` でコピー
