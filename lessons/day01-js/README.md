## 1. Python・Rust との違い（3分）

| やりたいこと | Python | Rust | JavaScript |
| --- | --- | --- | --- |
| 再代入しない変数 | （仕組みなし） | `let x = 1;` | `const x = 1;` |
| 再代入する変数 | `x = 1` | `let mut x = 1;` | `let x = 1;` |
| 文字列に値を埋め込む | `f"{x}円"` | `format!("{x}円")` | `` `${x}円` `` |
| 等しいか比べる | `==` | `==` | `===`（`==` は使わない） |
| 数値の型 | `int` と `float` | `i32`・`f64` など | `number` ひとつだけ |
| 値がない | `None` | `Option::None` | `undefined` と `null` |
| 画面に出力 | `print(x)` | `println!("{x}")` | `console.log(x)` |

覚えるのは次の 3 点です。

1. **基本は `const`、再代入が必要なときだけ `let`**。古い書き方の `var` は使いません。Rust の「デフォルトは不変」に近い感覚で書けます。
2. **比較は `===`**。`==` は型を勝手に変換するので `"5" == 5` が `true` になります。
3. **数値は全部 64bit 浮動小数点数**。Rust の `f64` しかない世界です。`7 / 2` は `3.5` になります。

```js
console.log("5" == 5);  // true  ← 型を勝手に変換してから比較してしまう

```

```js
console.log(2980 * 1.1);         // 3278.0000000000005 ← 金額計算で事故のもと
console.log((2980 * 110) / 100); // 3278 ← 整数で掛けてから割ると安全
```

`2980 * 1.1` を `Math.ceil`（切り上げ）すると 3279 円になり、1 円ずれます。金額は「整数で掛けてから割る」と覚えておきましょう。

> **Rust 経験者向けの注意**：`const` は「変数に別の値を入れ直せない」という意味です。Rust の不変とは違い、配列やオブジェクトの**中身**は変更できます。
>
> ```js
> const list = [1, 2];
> list.push(3);   // OK: 中身の変更
> list = [9];     // TypeError: 入れ直しはできない
> ```

## 4. 確認クイズ（2分）

**Q1.** 次のうち、実行するとエラーになるのはどれ？

```js
const a = 1;   a = 2;         // (A)
let b = 1;     b = 2;         // (B)
const c = [1]; c.push(2);     // (C)
```

<details><summary>答え</summary>

**(A) だけ**です。(C) は変数 `c` に別の配列を入れ直していないので問題ありません。`const` が禁止するのは再代入だけです。

</details>

**Q2.** `"10" == 10` と `"10" === 10` の結果は？

<details><summary>答え</summary>

`true` と `false` です。`==` は文字列 `"10"` を数値に変換してから比べます。実務では `===` を使い、ESLint（JavaScript のチェックツール）の `eqeqeq` ルールで `==` を禁止しているチームも多いです。

</details>

**Q3.** `10 / 4` の結果は、Python・Rust（`i32`）・JavaScript でそれぞれいくつ？

<details><summary>答え</summary>

Python は `2.5`、Rust は `2`、JavaScript は `2.5` です。JavaScript で整数の割り算（切り捨て）をしたいときは `Math.floor(10 / 4)` または `Math.trunc(10 / 4)` を使います。

</details>
